# Identical Car Chart v1.18 — self-contained copy (2026-11-02)

Open `index.html` in a browser (serve the folder over http for the front views, e.g. `python3 -m http.server`;
the side views work from a plain file:// open as well).

- `index.html` — the chart (also published at https://claude.ai/artifact/SQLziPkb5ir5kasuaUEHrc, Version 30 = v1.18)
- `img/`, `img_manifest.json` — side-view pictures (WebP) and `img/fronts.json` (front views, packed); 34 side pictures new since v1.14a, see below
- `img/sides.json`, `img/sides_packed.txt` — the 29 new side pictures packed as base64 (only the published artifact needs them, see "Artifact file limit"); this folder has every picture as a single file too
- `research/` — model research files, incl. `research/countries/brand_countries.json` (brand countries for the flags; the poster build needs it)
- `build/` — generator (`gen.py`), merge pipeline, overrides, picture tooling (`build_ext.py`, `ext_JUDGED.md` = source and treatment of every external picture, `ext_manifest.json`, `pack_fronts.py`, `pack_sides.py`), drive data, checks, the v1.15 research brief and target list (`v115_brief.md`, `v115_targets.json`, `v115_chrome_howto.md`), the thirteen research-group reports (`v115_reports/`), and the data patches of this version (`patch_v115.py`, `patch_v115b.py`, `p115c.py`, `p115d.py`, `apply_log.md`)

v1.17 (2026-11-02), published as Version 29. Only `index.html` and `build/gen.py` changed (pictures and data as in v1.15a). Raven reported that, on car-chart.forestraven.net, the three smallest classes plus the hybrid powertrains still left an empty Volkswagen column. That is the v1.15 behaviour (Volkswagen has hybrids only from the compact class up, so its column emptied but stayed); the v1.16 page hides it. The live site was serving v1.16 at the time and behaved correctly in Raven's own browser, and a sweep of 7,326 filter combinations (`build/sweep_v117.js`: every powertrain subset, every drive subset, the twins toggles and every single group, each against 36 class selections) found no empty column, empty row or orphaned tile, so the report came from a stale copy of the page (browser cache or a tab loaded before the upload). Change: the header now shows the chart version ("Version 1.17", `CHART_VERSION` in `gen.py`), so a reader can tell which release is loaded. The web release was asked to make the server revalidate `index.html` on every visit (`Cache-Control: no-cache`) so that a new upload is never masked by a cached page.

v1.18 (2026-11-02), published as Version 30. Changed: `index.html`, `build/gen.py` (version 1.18), `build/drive.json`, and the new `build/drive/` folder (the drive research of v1.8: nine batches and results, `verified.json` with the hand-checked records, `merge_drive.py`; plus this version's `v118_quadricycles.json` and `v118_report.md`). Raven asked to eliminate the "Drive not researched" entries. They were the 12 light quadricycles added in v1.11 after the drive research of v1.8 (Aixam City, Coupé, Crossover, D-Truck/e-Truck, Easy, e-Scouty; Ligier JS50, JS60, Myli, Pulse 4; Chatenet CH46; Casalini 650). All twelve are front-wheel drive and none is sold with all-wheel drive. Sources: the six Aixam models are stated by Aixam itself (aixam.it and aixam-pro.it spec tables, "Ruote motrici: trazione anteriore"; the electric versions "Anteriori"); Ligier JS50 and Myli by the ADAC Autokatalog ("Antriebsart: Vorderrad", diesel and electric); Ligier Pulse 4 by Spanish catalogues (motor.es, quecochemecompro); Casalini 650 by ADAC's entry for the M20, of which the 650 is the 2026 version with the new Kubota engine (the Austrian general importer sells it as "M20 650"); Chatenet CH46 by a Polish catalogue entry for the earlier Lombardini-engined CH46 (marked unverified, since the entry's other engine data are wrong and Chatenet's site and manual say nothing); Ligier JS60 (2026) inferred and marked unverified: Ligier's page, equipment sheet and press release give no driven wheels and no catalogue has the new car yet, while the previous JS60 and the JS50/Myli with the same REVO D+ and 11.04 kWh powertrains are front-wheel drive per ADAC. Ligier's own pages never state the driven wheels, which is why its models are "medium" (flagged "not checked on a manufacturer page" in the detail panel). The "Drive not researched" chip of the Drive filter has disappeared (no model is left without a record); confidence now high 424 / medium 111 / low 2. Side note from the research: ADAC lists diesel versions of the Myli LAB and MAX from 09/2026, which the chart already records (powertrains diesel + BEV). Details per model in `build/drive/v118_report.md`; the records in `build/drive/v118_quadricycles.json` and `build/drive/verified.json`.
